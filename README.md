# Predictive-model---Maxa-liga-2026
Using Python for scrapping the data from the website of Czech hockey Hokej.cz, SQL for filtering the data and tables This simulation will run in Python and depending on the SQL values, it will predict the remaining matches of the league and determine the final ranking. Results would be regularly visualized using Power BI tools.

# 01_python_scrapers
This directory contains Python scraper codes for gathering data from website Hokej.cz. Currently 2 scrapers created. 
maxa_liga_tabulka.py - current rankings of teams including total points, shots, etc. 
maxa_liga_zapasy.py - list of all matches that have been already played ('odehrano') or are scheduled ('neodehrano') 

# 02_sql_queries 
This directory contains SQL queries which extract from CSV files generated by Python scrapers in the previous step.
